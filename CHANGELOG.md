# Changelog

All notable changes to this checklist. Versions follow MAJOR.MINOR.PATCH:
a new feature bumps the middle number, a small fix or text change bumps the last one.

## [1.2.0] - 2026-11-14
### Added
- Items & Equipment: swipe (or drag) sideways, use a sideways scroll, or tap the new ‹ › buttons to switch
  between Select Item and Equipment. Scrolling the mouse wheel over the tab bar works too.
- The switch now turns like the N64 pause menu, swinging the next screen in like the side of a box.
- Two dots under the menu show which screen you’re on.

### Changed
- The selected tab is now gold so it’s obvious which screen you’re on.
- Gold Skulltula token rewards are hidden behind a “Reveal rewards” button.
- Chapter 9 is renamed “Death Mountain Clean-Up”.

## [1.1.1] - 2026-11-14
### Changed
- Navi is bigger, with a larger speech bubble, and gives a little hop every few seconds so she reads as a button.
- Her line is now “Where was I?”, which fits both getting lost and picking up after a break.
- Navi’s badge is now a complete circle; the bottom used to look cut off.
- The search box has a Lens of Truth label so it’s easy to spot.

## [1.1.0] - 2026-11-14
### Added
- Navi now handles “What’s next?”: tap her, next to the search bar, to jump to your next unchecked line.
  She replaces the old “Next up” button in the filter row.
- Item pop-ups now have rays of light and a glow, like finding an item in the game.
- The Notes button is bigger and has golden rays around it so it stands out while scrolling.
- The version number is shown in the page footer.

### Changed
- The search box placeholder is shorter to make room for Navi.

## [1.0.1] - 2026-11-13
### Added
- LICENSE file and a copyright line in the page footer.

### Changed
- Offline cache version bumped so installed copies pick up the new footer.

## [1.0.0] - 2026-11-13
### Added
- First public release on GitHub Pages: 29-chapter route, Quest status, Items & Equipment,
  Notes, filters, search, light and dark mode, offline support and home-screen install.
