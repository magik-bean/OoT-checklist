# A Completionist’s Checklist: Ocarina of Time (Remake)

A fan-made, spoiler-light 100% checklist. Not affiliated with or endorsed by Nintendo.

## Publish on GitHub Pages
1. Create a new repository (e.g. `oot-checklist`) and upload every file in this folder to the root.
2. Settings → Pages → Build and deployment → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`. Save.
3. After a minute or two the site is live at `https://<your-username>.github.io/oot-checklist/`.

## Install on a device
- iPhone/iPad: open the link in Safari → Share → Add to Home Screen.
- Android: open it in Chrome → ⋮ → Install app (or Add to Home screen).
- Windows/macOS: Chrome or Edge shows an install icon in the address bar.

Progress saves on each device. Use "Back up or restore" at the bottom of the page to move it between devices.

## Updating
Replace `index.html` with a new build and commit. When you change other files, bump `CACHE` in `sw.js` (e.g. `oot-checklist-v2`) so installed copies refresh.
